## U-20261119-01 · 2026-11-19 · GUI rebuilt: sidebar, themes, layouts that adapt to the width · #done #gui #i18n #docs

- **What**: the desktop GUI was rebuilt around a new shell, with every page's behaviour and test accessors kept.
  - **Shell** (`thesisagents/gui/main_window.py`): the top `QTabWidget` became a sidebar (`widgets/nav_rail.py`) with Search, Enrich and Deck, and Settings pinned at the bottom, beside a page stack. Each page has a title and a one-line subtitle. After a search the Enrich and Deck entries show the paper count (`Enrich · 25`). The status bar shows `Working…` and an indeterminate progress bar while any page has work on a worker thread (new `busy_changed` signal on the Search, Enrich and Deck pages). `Ctrl+1` … `Ctrl+4` switch pages.
  - **Adaptive layout** (`widgets/responsive.py`): the window width maps to a size class, compact below 760 px, medium to 1179 px, expanded from 1180 px, and every page is told when it changes. Compact collapses the sidebar to 64 px icons (labels in tooltips) and hides the Authors and DOI result columns. Expanded puts each page's controls in a 420 px column beside its results, medium and compact stack them, with a draggable handle. The controls scroll on their own and the main buttons stay pinned below them. Form labels move above their fields when their own card is narrower than 460 px. Source and export-format check boxes re-flow into as many aligned columns as fit (`ReflowGrid`). Settings shows two columns, stacked when compact. The minimum window size went from 900×600 to 640×480.
  - **Theme** (`thesisagents/gui/theme.py`): light and dark palettes applied as one app-wide stylesheet on the Fusion style, chosen in **Settings → Theme** (*Follow the system*, the default, *Light*, *Dark*, QSettings key `ui/theme`). It applies on save with no restart, and *Follow the system* tracks the OS switching while the app is open. The light sidebar uses the deck navy `#1F3A66` and the accent is the deck highlight `#2563EB` (`#60A5FA` in dark). The app theme is separate from the deck's **Dark mode**.
  - **Icons** (`thesisagents/gui/icons.py`): sidebar icons, check marks and combo / spin arrows are drawn with `QPainter` in the theme's colours, so no SVG image-format plug-in has to be bundled by Nuitka or PyInstaller. The glyph PNGs the stylesheet references go to a private per-process `mkdtemp` directory removed at exit.
  - **Small improvements**: Enter in the query field runs the search, double-clicking a result opens the paper's page (only `http` / `https`, a `file:` or other link from a source record is ignored), cards replace `QGroupBox` frames, tables use alternating rows.
- **i18n**: 15 new keys in all 14 languages (`nav.toggle`, `status.busy`, four `page.*_subtitle`, `search.card_query` / `card_filters` / `card_library` / `results_title`, `settings.card_browser`, `settings.theme_label` / `theme_system` / `theme_light` / `theme_dark`). `settings.saved_message` now says the theme applies at once and the language after a restart.

## U-20261119-03 · 2026-11-19 · GUI: cancel, snowball bounds, results subset, remembered forms · #done #gui #i18n

- **What** (`progress.md` #19, #21, #22, #26, the first stage of the GUI roadmap):
  - **#19 Cancel**: `AsyncWorker` (`thesisagents/gui/workers.py`) gained `cancel()`, safe from the UI thread, and a `cancelled` signal. It cancels the coroutine's task at its next `await`, so `finally` blocks still run (a search still closes its HTTP clients). A result that arrives after a cancel is dropped in favour of `cancelled`. The Search page shows **Cancel** while a search runs, and a cancelled search keeps the previous results. The Enrich page shows **Cancel** during a run: unreached papers are marked *not run (stopped)* and keep their search record, so the output still has every paper. A collection that arrives while a run is going (a new search, changed ticks) is held and applied when the run ends, where before it would have replaced the table mid-run and pointed the run at the wrong rows. Exports stay uncancellable, stopping one half-way would leave partial files.
  - **#21 Snowball bounds**: *Advanced snowball settings* on the Search page exposes seeds, depth, papers per seed, total and the relevance floor (`SnowballBounds`), prefilled with the CLI defaults and passed to `snowball()`.
  - **#22 Results table**: `PapersTableModel` gained check boxes on the title column (every paper of a new result starts ticked) and a `SORT_ROLE` (numbers for year and citations, a missing value as -1). The new `PaperFilterProxy` sorts and filters by words across title, authors, venue and DOI and by source. Filtering only hides rows, it never unticks. Enrich, Deck and the Search export receive only the ticked papers (`SearchPage.selected_collection()`). **Tick shown** / **Untick shown** act on the visible rows. Right-click a row for *Open paper page*, *Open PDF*, *Copy DOI* and *Copy BibTeX* (new public `bibtex_entry(paper)` in `thesisagents/exporters/bibtex.py`). Links still open only for `http` / `https`. The table keeps the ranked order until a header is clicked. Title and authors start at 300 / 150 px and the table scrolls sideways when narrow, because a stretched title had shrunk to a few characters beside six content-sized columns.
  - **#26 Remembered forms**: the Search, Enrich and Deck pages have `save_form` / `restore_form`. `MainWindow.closeEvent` saves them under `form/search`, `form/enrich`, `form/deck`, and the next window restores them. The Deck filename stem is left out so the next export does not overwrite the last. Missing or invalid values keep the defaults.
  - Also: `PaperFilterProxy` uses Qt 6.10's `beginFilterChange` / `endFilterChange` when present and falls back to the deprecated `invalidateFilter()` for PySide6 6.7, and table check boxes take the theme's check-box style.

## U-20261119-04 · 2026-11-19 · GUI Library page: overview, papers with links and checks, searches · #done #gui #library #i18n

  - **Overview**: papers, searches (runs), citation links, year span, papers per source, stored identifier checks per status (`LibraryStats`).
  - **Papers** tab: the papers matching the find box (`Library.search`, the search ranker), sortable, with sources, times seen and last seen. Every value in the detail panel is HTML-escaped, titles come from remote APIs.

  - **Send to Enrich and Deck** emits the listed papers with their links (`Library.collection`), wired like a search result, and the sidebar badges update.

## U-20261119-05 · 2026-11-19 · GUI: template check, deck review, enrichment hand-off to an agent · #done #gui #pptx #i18n

- **What** (`progress.md` #23, #27):
  - **#23 Deck page**: **Check template** runs `exporters.template.validate_template` (with the config and, when **Dark mode** is ticked, the dark-export warnings) on a worker thread without exporting. **Review a deck…** runs `exporters.review.review_deck` on any `.pptx`, the picker starting at the deck the last export wrote. Each shows its full text report (the same `format_report` text as `thesisagents validate-template` / `thesisagents review`) in a new non-modal `ReportDialog` (`thesisagents/gui/widgets/report_dialog.py`, monospace, Copy / Close), and a one-line verdict on the status line (*usable* / *not usable, N problem(s)*, `Deck review: PASS` / `FAIL, N problem(s)`). A file that is not a deck reports `Check failed: …`. Reports stay English, like the CLI's.
  - **#27 Enrich page**: a card *No API key? Hand off to an agent* with **Export for an agent…** and **Import summaries…**, built on the new `thesisagents/gui/handoff.py`. `write_handoff` writes a JSON file (`format: "thesisagents-agent-handoff"`, `version: 1`) with the papers and their PDF links, the summary language, an empty `summary_template` showing every `PaperSummary` field, and instructions mapping the fields to thesis sections. `read_handoff` attaches each filled summary to the paper with the same `key` (`dedup_key()`), counts entries for unknown papers, keeps a summary the file leaves empty, and refuses (`HandoffError`) a file over 20 MB, not JSON, nested too deeply to parse, of another format or version, with `papers` not a list, an entry without a text `key` or a `paper` object, a summary that is not an object, or a paper the model cannot read. The file is untrusted, so every malformed shape becomes a message on the status line, never a traceback out of a Qt slot (found by the DoD security read with a probe of hostile files). Only the summary is taken from the file, the papers' own fields are kept. Imported papers show *ok* and go to the Deck page.
  - The Enrich subtitle no longer says an API key is required. It names both paths.
- **i18n**: 20 new keys in all 14 languages (`action.copy`, `action.close`, nine `deck.*` for the check and review, `deck.check_failed`, seven `enrich.agent*` / `enrich.card_agent`), and `page.enrich_subtitle` rewritten in all 14.
